## Why TypeScript?

As a C# developer, I found TypeScript to be incredibly familiar:

\`\`\`typescript
// TypeScript - looks familiar to C# developers!
interface User {
  id: string;
  name: string;
  email: string;
}

function greetUser(user: User): string {
  return \`Hello, \${user.name}!\`;
}
\`\`\`

Compare this to C#:

\`\`\`csharp
// C# - very similar!
public interface IUser {
    string Id { get; set; }
    string Name { get; set; }
    string Email { get; set; }
}

public string GreetUser(IUser user) {
    return $"Hello, {user.Name}!";
}
\`\`\`
